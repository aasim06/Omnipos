# Advance POS (Vite + React + Tailwind CSS)

Modern retail Point of Sale (POS) and inventory management web application built with **React**, **Vite**, **React Router**, and **Tailwind CSS v4**.

## Features

- **Overview Dashboard**: Live retail metrics, revenue tracking, and analytics.
- **Mini Mart POS**: Quick cashier checkout, product searching, and cart management.
- **Stock Management**:
  - Stock In (incoming inventory batches, unit cost & retail prices)
  - Stock Out (wastage, damage, expiration logging)
  - Stock History (full audit log of all inventory movements)
- **Admin Console**: Catalog management, category manager, sales analytics, and settings.
- **Offline / Local Data**: Persistent local storage with automatic seed data initialization.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```
